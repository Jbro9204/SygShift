## Measured reason

Local nested plans show 51,041 shift primary-key heap lookups for the stale-event candidate selection. The existing thirteen shift indexes have no equivalent covering index. The proposed nonunique partial B-tree covers the exact lookup and its existing `canceled_at IS NULL` predicate:

```sql
CREATE INDEX CONCURRENTLY shifts_timekeeping_candidate_cover_idx
ON public.shifts (id) INCLUDE (starts_at, ends_at, schedule_id)
WHERE canceled_at IS NULL;
```

The existing primary key continues enforcing identity uniqueness. No function, formula, permission, row or compatibility relation changes. The index does not replace any existing index or restrict canceled historical records.
