# Document Center Usability Overhaul

Date: 10/01/2026  
Status: Production database installed; application deployment verification pending

## Outcome

The existing Document Center has been overhauled so Guardianship Security's
current controlled PDFs can be completed as real working forms. This is not a
replacement document system and it does not create a second set of HR forms.
It repairs how the existing source PDFs are classified, mapped, completed,
previewed, and filed while preserving the original source document.

The overhaul directly addresses the reported failures where generic
`[Enter / Sign]` placeholders were assigned to the wrong purpose, date cells
were treated as signatures, field labels in the right panel did not explain
what belonged in each box, and entered values covered or broke the surrounding
body paragraph.

## Form mapping and guided completion

- Rebuilt flattened-placeholder detection around the actual PDF text geometry,
  nearby section headings, table columns, signer roles, and field purpose.
- Distinguished text, long-text, date, checkbox, choice, printed-name, and
  signature inputs instead of treating every generic entry cell as the same
  control.
- Added semantic labels, descriptions, and section grouping so the guided
  field list identifies the person, purpose, and destination of each entry.
- Added multi-line table-heading support for forms whose column labels are
  split across separate PDF text runs.
- Kept native AcroForm fields supported alongside flattened Guardianship
  placeholders.
- Added a review state for any field that cannot be mapped safely. Ambiguous
  mappings cannot be silently finalized.
- Added a 500-field safety limit so an unexpectedly complex or malformed PDF
  must be deliberately mapped instead of being partially completed.
- Preserved manual corrections during employee prefill. Refreshing or changing
  an employee updates only values that were generated by the system; it does
  not overwrite user-entered content, defaults, or placed signatures.

## Finished-PDF integrity and body-text reflow

- Replaced approximate character positioning with measured PDF font geometry
  for flattened placeholders.
- Reconstructed affected inline body lines as a unit so inserted names, dates,
  sites, and other values read naturally with the original punctuation and the
  surrounding sentence instead of leaving gaps or drawing over paragraph text.
- Limited erasure masks to verified source text and field bounds so neighboring
  labels, boxes, borders, and narrative content remain intact.
- Added bounded single-line and multi-line fitting. Long values scale or wrap
  inside the intended field rather than spilling into the next section.
- Centered vector checkbox marks in their printed targets and fitted signatures
  to the exact signature box while preserving the signature aspect ratio.
- Added completed-PDF preflight checks for invalid geometry, unsupported field
  types, unresolved mapping reviews, field collisions, and body-content risks.
- Prevented ordinary flattened PDFs from receiving an empty AcroForm dictionary
  during export. Existing native fields are updated and flattened only when the
  source actually contains them.
- Cleared stale source bytes and blocked final output during a source-document
  change so a delayed detection result cannot combine one PDF with another
  PDF's field map.

## Usability, responsiveness, and accessibility

- Reorganized the workbench around plain-language field groups, completion
  status, mapping readiness, and a direct **Show on form** action.
- Kept the document, field editor, side panel, and final actions reachable on
  phones, small laptops, short screens, and high browser zoom.
- Added compact one-column behavior for narrow effective viewports without
  hiding the active field, preview, download, file, or send actions.
- Preserved a minimum 44-pixel touch target for primary compact controls and
  improved footer wrapping so actions do not overlap or fall below the screen.
- Added accessible disclosure state and relationships for expandable library
  details and retained keyboard-operable controls throughout the workflow.
- Improved long-title and metadata wrapping in both the source library and
  permanent-record list.

## Source library and permanent-record separation

- Added a persisted reviewed source subtype that distinguishes reusable
  controlled forms from guides/reference material, training forms, training
  reference material, and unclassified sources.
- Separated the Document Center into **Forms & source catalog**,
  **Guides, policies & training**, and **Saved document records** so reusable
  company sources are no longer presented as completed employee files.
- Added clear source-type, lifecycle, availability, filename, record class,
  section, and related-module information without forcing technical metadata
  into the primary row.
- Restricted **Start a new form** to adopted form-like sources. Guides,
  policies, handbooks, job descriptions, and training reference material remain
  preview/download resources rather than editable employee forms.
- Kept unclassified, draft, and retired sources fail-closed and preview-only.
- Embedded source metadata in the bounded document-workspace response and
  paged library response. The interface no longer fans out a separate request
  for every displayed record.
- Blocked the generic archive action for an active company-library source and
  rejected any attempt to register an employee-file document as the reusable
  company source.

## Controlled adoption and training safety

- Added an item-by-item **Adopt for use** workflow for authorized HR document
  managers. Adoption requires recent MFA, an audit reason, the exact current
  source checksum, and the expected source update time.
- Rechecks management permission, company ownership, source classification,
  source availability, and checksum at the database boundary before adoption.
- Restricted registration to `draft_for_adoption`; registration cannot bypass
  the reviewed adoption workflow by declaring an item adopted.
- Keeps draft and retired training modules inactive and non-assignable. A
  training course version is published only after its source is formally
  adopted.
- Reconciles earlier training catalog eligibility to the recorded source
  lifecycle without deleting or rewriting existing employee assignments or
  immutable published versions.
- Records source registration and adoption in the protected HR document access
  history.

## Security and preservation

- The database routines remain service-only, use a fixed empty `search_path`,
  and recheck the actor's effective permission at the database boundary.
- Original source PDFs remain unchanged. A working copy and its completed
  rendition are separate from the controlled source record.
- No employee document, employee-file association, historical version,
  signature evidence, existing training assignment, schedule, timekeeping,
  payroll, role, or permission record is deleted or rewritten by this overhaul.
- The schema change is additive and forward-only. Existing Worker versions can
  continue using the compatibility registration path during rollout, while new
  clients use the reviewed source subtype.

## Rollback and recovery

- Application rollback may use the prior healthy Worker only while the new
  source-metadata migration remains backward compatible with that revision.
- The database migration is not edited or reversed after application. Any
  correction must be a new forward migration that preserves source metadata,
  lifecycle history, training assignments, document versions, and access
  events.
- Formal source adoption is an audited business action. It is not silently
  undone by an application rollback; retirement or correction must use the
  controlled lifecycle workflow.

## Remaining limitation until release verification closes

The 537 imported sources remain drafts unless an authorized HR document manager
reviews and adopts each intended operational form or training item. This
overhaul provides the safe adoption workflow; it does not silently approve
legal, HR, policy, or training content on management's behalf.
